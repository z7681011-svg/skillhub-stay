# skillhub-stay

SkillHub Stay is a Flutter-based mobile application prototype that allows users to browse stays with local skill experiences, view stay details, select booking options, review booking summaries, and explore profile and booking management screens.

## Main Features
- Splash and welcome screens
- Home page with recommended stays
- Available stays and stay details
- Booking option selection
- Booking summary and payment interface
- My Bookings page
- Profile and privacy controls

## Technology
- Flutter
- Dart
- Android Emulator
